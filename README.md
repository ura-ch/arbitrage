# arbitrage
Получает данные о ценах с CoinMarketCap API
Получает данные о ценах в реальном времени через WebSocket от Binance.
Анализирует данные для поиска возможностей арбитража.
Сохраняет результаты в базу данных MongoDB.
Использует логирование winston для отслеживания событий.
Использует модульные тесты для проверки функций.
